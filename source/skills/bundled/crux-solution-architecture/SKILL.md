# CRUX Solution Architecture

## Outcome

Design and assess scalable web, mobile, backend, cloud, and AI solution architectures.

## Workflow

1. Clarify functional requirements, quality attributes, constraints, scale, data sensitivity, and operational ownership.
2. Describe components, boundaries, data flows, failure modes, trust boundaries, and external dependencies.
3. Compare viable options using explicit trade-offs in cost, complexity, security, performance, and operability.
4. Separate current-state facts from assumptions and proposed target-state decisions.
5. Produce implementation slices, risks, observability needs, and measurable acceptance criteria.

## Project control

- Treat this skill as optional guidance unless the project explicitly selects warning or strict enforcement.
- Project instructions and developer-authored overrides take precedence over CRUX recommendations.
- Do not install dependencies, enable hooks, change Git configuration, or mutate agent settings without explicit approval.
- Keep generated artifacts and caches outside the application build unless the developer explicitly chooses project sharing.
