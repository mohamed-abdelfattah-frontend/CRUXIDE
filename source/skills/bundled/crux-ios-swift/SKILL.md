# CRUX iOS & Swift

## Outcome

Guide native iOS applications using Swift, SwiftUI, structured concurrency, and platform security.

## Workflow

1. Keep SwiftUI views declarative and move state ownership and side effects to explicit observable boundaries.
2. Use structured concurrency with clear cancellation, actor isolation, and main-thread transitions.
3. Design navigation, deep links, background tasks, permissions, Keychain storage, and lifecycle recovery.
4. Support Dynamic Type, VoiceOver, localization, reduced motion, and device-size variation.
5. Test models, concurrency behavior, view state, integrations, and archive builds.

## Project control

- Treat this skill as optional guidance unless the project explicitly selects warning or strict enforcement.
- Project instructions and developer-authored overrides take precedence over CRUX recommendations.
- Do not install dependencies, enable hooks, change Git configuration, or mutate agent settings without explicit approval.
- Keep generated artifacts and caches outside the application build unless the developer explicitly chooses project sharing.
