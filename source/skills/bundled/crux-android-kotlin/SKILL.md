# CRUX Android & Kotlin

## Outcome

Guide native Android applications using Kotlin, Compose, lifecycle-aware state, and secure platform APIs.

## Workflow

1. Use lifecycle-aware state collection and keep UI state immutable and observable.
2. Separate Compose UI, use cases, repositories, data sources, and platform services.
3. Handle configuration changes, process death, permissions, deep links, background work, and offline recovery.
4. Use platform-backed secure storage and minimize exported components and excessive permissions.
5. Test ViewModels, Compose behavior, navigation, persistence, and release builds.

## Project control

- Treat this skill as optional guidance unless the project explicitly selects warning or strict enforcement.
- Project instructions and developer-authored overrides take precedence over CRUX recommendations.
- Do not install dependencies, enable hooks, change Git configuration, or mutate agent settings without explicit approval.
- Keep generated artifacts and caches outside the application build unless the developer explicitly chooses project sharing.
