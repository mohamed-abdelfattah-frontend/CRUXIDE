# CRUX Figma-to-Code

## Outcome

Translate Figma screens and components into maintainable code with measurable visual fidelity.

## Workflow

1. Inspect the exact design node, variables, components, typography, spacing, states, and responsive intent.
2. Reuse existing repository components and tokens before introducing new primitives.
3. Translate layout intent rather than fixed screenshot coordinates.
4. Preserve accessibility semantics, keyboard behavior, RTL, localization, and content resilience.
5. Compare implementation renders against the reference and report unresolved mismatches.

## Project control

- Treat this skill as optional guidance unless the project explicitly selects warning or strict enforcement.
- Project instructions and developer-authored overrides take precedence over CRUX recommendations.
- Do not install dependencies, enable hooks, change Git configuration, or mutate agent settings without explicit approval.
- Keep generated artifacts and caches outside the application build unless the developer explicitly chooses project sharing.
